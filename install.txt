# Installation Guide

## Step-by-Step Setup (For Non-Coders)

### Step 1: Install Python

**Windows:**
1. Go to https://www.python.org/downloads/
2. Click "Download Python 3.12" (or latest version)
3. Run the installer
4. ✅ **IMPORTANT**: Check the box "Add Python to PATH"
5. Click "Install Now"
6. Wait for installation to complete
7. Close the installer

**Mac:**
1. Go to https://www.python.org/downloads/
2. Click "Download Python 3.12" (or latest version)
3. Open the downloaded file
4. Follow installation steps
5. Close the installer

**Verify Python is Installed:**
- Open Terminal (Mac) or Command Prompt (Windows)
- Type: `python --version`
- You should see: `Python 3.12.x` (or similar)

---

### Step 2: Download Scanner Files

**Option A: Download from GitHub**
1. Go to your repository
2. Click the green "Code" button
3. Click "Download ZIP"
4. Extract the ZIP file to a folder (e.g., Desktop/crypto-scanner)

**Option B: Copy Files Manually**
1. Create a new folder (e.g., Desktop/crypto-scanner)
2. Create 3 files inside:
   - `requirements.txt`
   - `crypto_scanner.py`
   - `README.md`
3. Copy the contents from your downloaded files

---

### Step 3: Open Terminal/Command Prompt

**Windows:**
1. Press `Windows Key + R`
2. Type: `cmd`
3. Press Enter

**Mac:**
1. Press `Command + Space`
2. Type: `terminal`
3. Press Enter

---

### Step 4: Navigate to Scanner Folder

In the terminal, type:

**Windows Example:**
```bash
cd Desktop\crypto-scanner
```

**Mac Example:**
```bash
cd Desktop/crypto-scanner
```

(Replace "Desktop/crypto-scanner" with wherever you put your files)

**Verify You're in the Right Place:**
Type: `dir` (Windows) or `ls` (Mac)

You should see:
- crypto_scanner.py
- requirements.txt
- README.md

---

### Step 5: Install Required Packages

In the terminal, type:

```bash
pip install -r requirements.txt
```

Press Enter and wait. You'll see:
```
Collecting streamlit...
Collecting ccxt...
Collecting pandas...
Collecting numpy...
Successfully installed...
```

**If you get an error**, try:
```bash
python -m pip install -r requirements.txt
```

---

### Step 6: Run the Scanner

In the terminal, type:

```bash
streamlit run crypto_scanner.py
```

You should see:
```
You can now view your Streamlit app in your browser.

Local URL: http://localhost:8501
```

Your web browser should open automatically with the scanner!

---

## Common Installation Issues

### "Python is not recognized"
**Problem**: Python not added to PATH during installation

**Solution**:
1. Uninstall Python
2. Reinstall Python
3. ✅ **Make sure to check "Add Python to PATH"**

### "pip is not recognized"
**Solution**:
```bash
python -m pip install -r requirements.txt
```

### "Permission denied" or "Access denied"
**Solution**:
```bash
pip install -r requirements.txt --user
```

### "ModuleNotFoundError: No module named 'streamlit'"
**Solution**:
Install packages one by one:
```bash
pip install streamlit
pip install ccxt
pip install pandas
pip install numpy
```

### Scanner won't open in browser
**Solution**:
Manually open your browser and go to:
```
http://localhost:8501
```

## First-Time Use

### When Scanner Opens:

1. **Click the ">" arrow** on the left to open settings

2. **Configure Settings:**
   - Exchanges: Select "binance"
   - Entry Timeframes: Select "5m"
   - Max symbols: Set to 10
   - Refresh interval: Set to 60

3. **Click "Manual Refresh"**

4. **Wait for signals** (may take 1-2 minutes)

### If No Signals Appear:
- This is normal! Good setups don't appear constantly
- Try increasing "Max symbols" to 20-30
- Try adding "3m" timeframe
- Be patient - scanner is working correctly

## Running Scanner Next Time

You don't need to reinstall packages every time!

**Quick Start (After First Installation):**

1. Open Terminal/Command Prompt
2. Navigate to scanner folder:
   ```bash
   cd Desktop/crypto-scanner
   ```
3. Run scanner:
   ```bash
   streamlit run crypto_scanner.py
   ```

That's it!

---

## Stopping the Scanner

**To Stop:**
- Close the browser tab
- Go to terminal and press `Ctrl + C`
- Close the terminal window

**To Start Again:**
- Just run `streamlit run crypto_scanner.py` again

## Need Help?

**Check These First:**
1. Did you install Python correctly?
   - Test: `python --version` in terminal
2. Did you install packages?
   - Test: `pip list` should show streamlit, ccxt, pandas, numpy
3. Are you in the right folder?
   - Test: `dir` (Windows) or `ls` (Mac) should show crypto_scanner.py
4. Is your internet working?
   - Scanner needs internet to fetch market data

**Still Having Issues?**
- Re-read this guide carefully
- Make sure you followed every step
- Check for typos in commands
- Try restarting your computer
